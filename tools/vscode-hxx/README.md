# `vscode-hxx` (in-repo) — HXX/HEEx completions for Haxe

vshaxe (and the Haxe completion server) cannot offer semantic completions **inside string literals**, so
`HXX.hxx('...')` needs a small companion VSCode extension to provide tag/attr completions.

This extension reads `tmp/hxx-registry.json` generated by:

```bash
npm run docs:hxx:index
```

## Run locally (recommended)

1) Open this repo in VSCode.
2) Generate the registry JSON:
   ```bash
   npm run docs:hxx:index
   ```
3) Run the extension:
   - Open `tools/vscode-hxx/` in VSCode
   - Press `F5` (Run Extension)
4) In the Extension Development Host window, open a `.hx` file and edit an `HXX.hxx('...')` template.

## Settings

- `hxx.indexPath` (default: `${workspaceFolder}/tmp/hxx-registry.json`)

## Scope (initial)

- Tag completion for:
  - dot-components (`<.card ...>`)
  - slot tags (`<:header ...>`)
- Attribute completion for known component props/slot props (best-effort).
